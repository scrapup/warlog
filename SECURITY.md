# Security Policy

## Supported versions

Only the latest minor release of `@scrapup/warlog` published on npm receives security fixes.

| Version | Supported |
|---|---|
| Latest minor (`0.x`) | Yes |
| Older releases | No |

## Reporting a vulnerability

Do **not** open a public issue, discussion or pull request for a vulnerability.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/scrapup/warlog/security/advisories/new)
(Security tab → *Report a vulnerability*).

Include the affected version or commit, a description of the impact and the steps to reproduce.

## Response

Reports are handled on a best-effort basis by the maintainers. You will receive an acknowledgement
on the advisory. The fix is released first through the normal release flow (a new `vX.Y.Z` tag,
GitHub Release and npm version); the advisory is published after the release.
